# Sinchana – Full-Stack & AI Software Developer

> Portfolio and Interactive Projects Showcase designed from first principles with institutional startup diligence, typographic hierarchy, and visual craft.

---

## 🎨 Design System & Reference

- **Palette:**
  - **Dark Mode (Default):**
    - Background: `--bg: #160000;` (Deep warm oxblood / espresso)
    - Foreground: `--fg: #F1E7DF;` (Warm cream / oatmeal)
    - Accent: `--acc: #FF5A3C;` (Vibrant fiery vermilion)
    - Dim: `--dim: #B79F96;` (Muted warm taupe)
    - Border Line: `--line: rgba(241, 231, 223, 0.22);`
  - **Light Mode ("Change contrast" toggle):**
    - Background: `--bg: #F1E7DF;`
    - Foreground: `--fg: #160000;`
    - Accent: `--acc: #C7260A;`
    - Dim: `--dim: #5E4A44;`
    - Border Line: `--line: rgba(22, 0, 0, 0.25);`
- **Typography:**
  - Display: `Syne` (600, 700, 800)
  - Sans: `Hanken Grotesk` (400, 500, 600, 700)
  - Mono: `JetBrains Mono` (400, 500)
- **Key Architectural Features:**
  - **Hero Section:** Split-character animation, animated rotating geometric 8-point star, high-contrast action pills.
  - **Sliding Binary Marquee (`Strip`):** Pure deterministic binary streams sliding seamlessly across viewport boundaries.
  - **About Section:** 12-column architectural layout highlighting *Technical foundation*, *Product ownership*, and *Design sensibility*.
  - **Interactive Work Rows & Risk Radar:**
    - Expandable rows with institutional descriptions, metrics dl, and technologies.
    - 6-Axis interactive SVG **Risk Radar** (`Team`, `Market`, `Product`, `Traction`, `Efficiency`, `Moat`) built directly for the **Viabl** startup diligence engine.
  - **Visual Craft (Design Principles):** Typography, Layout and hierarchy, Colour and contrast, Interaction and motion, UI prototyping.
  - **Technical Arsenal (Skills):** Interactive category tab switching with arrow key navigation (`All`, `Languages`, `Frontend`, `Backend & APIs`, `Developer Tools`, `AI & Data`).
  - **High-Impact Contact Banner:** Full vermilion accent canvas with one-click copy email button, GitHub, and LinkedIn links.
  - **Admin Studio (`/admin`):** Password-protected CMS (`sinchana2026`) with live radar preview, project additions, and real-time updates.
